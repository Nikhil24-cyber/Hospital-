# 🏥 MediCare Hospital

A modern and responsive hospital website built with **HTML, CSS, and JavaScript**.

I created this project to practice frontend development and build a real-world healthcare website with a clean UI, responsive design, animations, login/signup, and appointment booking.

## ✨ Features

* 🏠 Modern hospital homepage
* 📱 Fully responsive design
* 👨‍⚕️ Doctors section
* 🏥 Hospital services
* 📅 Appointment booking
* 🔐 Login & Signup
* 🚑 Emergency information
* ⭐ Patient testimonials
* ❓ FAQ section
* 🎨 Smooth animations and hover effects
* 💾 LocalStorage for demo login and appointments

## 🛠️ Built With

* **HTML5** – Structure
* **CSS3** – Styling & responsive design
* **JavaScript** – Functionality & interactions
* **LocalStorage** – Demo authentication and appointment data

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. Open `index.html` using **Live Server**.

That's it! The website will open in your browser.

You can also run it using Python:

```bash
python3 -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

## 🔐 Note

The login/signup and appointment systems currently use **LocalStorage**, so they are mainly for frontend practice and demonstration.

For a real hospital application, I would connect the frontend to a backend using technologies such as **Java, Spring Boot, MySQL, REST APIs, and JWT authentication**.
